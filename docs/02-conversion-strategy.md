# Conversion Strategy

## Target Customers
- Home owners
- Apartment owners
- Commercial buildings
- Schools
- Hospitals
- Warehouses

## Primary Objections
1. Cost
2. Trust
3. Subsidy confusion
4. Maintenance
5. ROI

## Trust Builders
- Real installations
- Customer testimonials
- Warranty
- Subsidy assistance
- Financing
- Before/after savings
- Installation timeline

## Funnel
Ad/Search -> Homepage -> Calculator -> Trust -> Quote -> Inspection -> Installation
